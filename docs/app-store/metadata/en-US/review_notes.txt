REVIEW NOTES — Memento 1.0

1. NO ACCOUNT. NO DEMO CREDENTIALS.

No sign-in, no account, no login screen. Every feature is reachable after
install. Sign-In Information fields are blank for this reason, not by
oversight.

Onboarding offers an OPTIONAL app lock (Face ID or 4-digit PIN), skippable
via "Skip for now". If enabled, the lock screen offers a device-passcode
fallback. Do not look for a PIN in these notes; that fallback is the recovery
path.

2. HOW TO REACH THE CORE EXPERIENCE

The AI companion draws on what has been written; a fresh install has none.

  a. Complete onboarding (~20 seconds; skip the app lock).
  b. Journal → initials button top-left (VoiceOver: "Menu") → Profile →
     Settings → "Load Sample Entries". Adds a fictional journal. Reversible
     from the same row; never touches real entries.
  c. Return to Journal. Swipe left, or tap the chat icon top-right, and ask
     e.g. "what have I been writing about?". Replies cite sources; tap a
     citation to open the entry.

Capture: new-entry button, grant microphone and speech recognition, speak.
Photos: in a new entry, camera or picker (optional).
Location: a new entry may prompt for Location When In Use to attach a place
name. Coordinates are not stored. Denying location still saves the entry.
Export: Settings → "Export Your Journal" (Markdown + JSON; samples excluded).

NOTE: The companion uses Apple's on-device Foundation Models and needs Apple
Intelligence. On other devices, capture, timeline, search, and export still
work.

3. HOW DATA IS PROCESSED (Guidelines 5.1.1, 5.1.2)

No account. No analytics SDK. No third-party AI.

Entries are encrypted at rest with a Keychain key. The device is the system
of record. If the user is signed into iCloud, a private CloudKit replica can
appear on their other Apple devices. We cannot read that database. There is
no Memento server copy of the journal.

Text generation runs on device via Apple's Foundation Models. Speech uses
Apple's SpeechAnalyzer / on-device recognition; audio is not sent off-device
for transcription.

Settings includes an off-by-default toggle, "Share Quality Feedback". When
on, volunteered ratings and optional report text can be sent to our
verification database (hosted on Supabase). The question and answer leave
the device only when the user files a Report and chooses to include them.
Journal entries and chat history are not part of that path.

Privacy policy: Settings → About, and on the product page.

4. PERMISSIONS

  Microphone            voice entries, only while recording
  Speech Recognition    journal text (on-device)
  Camera                optional photo on an entry
  Location When In Use  optional place name; coordinates not stored
  Face ID               optional app lock; LocalAuthentication only,
                        never used for identification

No contacts, calendar, or tracking permission. No tracking.

5. AGE RATING AND CONTENT

Private single-user journal. No sharing, messaging, social features, in-app
browsing, or ads.

The companion talks about what the user wrote. It does not diagnose, offer
treatment, or present as a medical product. If an entry suggests possible
crisis, it shows a static support-resource card rather than advice.

6. WHAT IS IN THIS VERSION

Voice and text capture; photos; optional place name; searchable timeline; AI
companion with citations; Markdown/JSON export; optional Face ID or PIN;
optional iCloud private replica; opt-in quality-feedback sharing.
