What a journal does to the model

Four hundred self-play conversations, twenty to fifty messages each, against journals holding zero, eight and two hundred and sixty-two entries. Both sides of every conversation were generated on-device; every assistant turn went through the production Ask path, so retrieval, turn classification, channel selection and citation reconciliation were all live.

The result

The fabrication defect did not close. It moved.

Spec 046 was written about a model that invented journal entries when it had no journal to draw on. The evidence-first pipeline fixed that, comprehensively. But the same scorer, pointed at a nine-month archive for the first time, fires on roughly half of all turns — and the spans it catches are a different failure: the model italicising the person's own words back at them. Under the output contract, italics mean a verbatim journal quote.

The spans themselves

What the scorer actually caught

A rate is not evidence. hall.fabricatedQuote at roughly half of all seeded turns is either a model inventing entries or a scorer whose definition does not survive a real conversation, and only the text settles which. These are verbatim, with the offending span highlighted.

An unscored failure mode

Nothing checks an asserted date

A reply can name a date no entry carries and pass every check. On a seeded arm a date can legitimately be right, so those counts are not error counts — but on a zero-entry arm every asserted date is invented by construction, and that column should read zero.

Why this is not just a missing check

Spec 046's own motivating example is one of these turns — "I don't see anything from that stretch — the entry from March 12 shows a spike in missed classes", on the arm with no journal at all — and its violations array is empty. Elsewhere the model quotes a real entry verbatim and attaches a date that entry does not have; the only code that fires is hall.uncitedQuote, which names the attribution and not the invention. Two different defects are reaching one code again.
